# Existing Self Kits

Book Self kits worth offering to this crew, alongside the custom kits in this folder — never instead of them (Plan A.1 rule 1). Each entry names the themebook, the page, and a one-line re-flavor for Palisade. Un-listed kits from the same themebooks are still legal choices; this page surfaces the ones that fit this Series' concept and Key Players best.

| Corporate Citizenship | 198 | Use as-is or take one of this folder's three corp-specific versions ([[meliora-citizenship]], [[orison-citizenship]], [[api-citizenship]]) for a sharper fit. |
| Criminal Syndicate | 198 | The Almoners, played straight — or take [[almoners-associate]] for a Palisade-specific card. |

## Canon and flags

- Book content offered alongside custom content, per Plan A.1 rule 1 and Brief §0.1 — nothing here replaces a custom kit in this folder.
- Rarity note: none of these recommendations imply one of the five is common; Self kits describe circumstance, not the five (Bible §2).
