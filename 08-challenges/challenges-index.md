# Challenges README

Index for `08-challenges/`. [[generic-reuse-map]] points every generic pilot need at a core-book Challenge already in print; `custom/` and `power-sets/` hold what no book profile or Key Player covers on its own. WP1 also placed one series-level Challenge here directly: [[secret-war-goes-public]] (the public-war Countdown). This folder is **MC-only** ([[README|vault README]] §"Player-safe vs MC-only").
