# Generic Reuse Map

Every generic need the pilot will have, mapped to the core-book Challenge that covers it, its page, and a one-line Palisade re-flavor (Plan A.6: "Reuse map: when a core/tokyo Challenge fits a generic need, record it here with page and any re-flavor; write a full custom file only for setting-specific entities"). None of these need a new file — the MC pulls the book's profile as printed and reads the re-flavor line for the fictional dressing. Setting-specific entities that no book profile fits are written in full in `08-challenges/custom/` instead ([[challenges-index|see the index]]).

Re-flavoring never changes a Limit, a Consequence, or a tag structure — only the description, the story tags' proper nouns, and (where noted) which Key Player fields it. Splat NPCs pulled from this table still obey PC canon (Plan A.6): if a re-flavored Gang Member happens to be a Howler mid-shift, apply [[leash-frenzy-pack]] on top rather than inventing new vampire/werewolf rules here.

## Source-Touched & Conjurations — via `[TAO-REINTERPRETED]` only

Per Brief §3.1–3.2 and [[conflict-register]] CR-1, nothing in Palisade is a legend-Mythos. Where the book's Source-Touched & Conjurations category (Core p. 315–318) is reused at all, it is reused only under this reinterpretation — never as a Source, a Mythoi being, or a Conjuration with a will of its own.
