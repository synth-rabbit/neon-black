# Open Questions

Facts the setting needs that neither the Bible nor the Brief provides. Brief §12: *surface to the GM; do not fill.* Every item from Brief §12 is here, plus the Bible `[OPEN]` items the Brief did not restate. The "Owner / where it surfaces" column names the work package that will hit the question first and the file where the hook must be left. Files cite rows as `(OQ-n)` ([[style-guide]] §7).

Three kinds of status: **GM** (only the GM can answer), **proposed** (a build package has offered a flagged proposal the GM may adopt), **must not fill** (the GM has explicitly reserved the answer).

## Status board (WP8)

One line per question, in a closed vocabulary (BC-180): **open** (nobody has proposed an answer; play or the GM decides when it arises), **proposal on file** (a package offered a flagged answer the GM may adopt — the file where it lives is named), **GM decision needed** (a job or a file depends on the answer before session one, or the Bible reserves it), **resolved** (closed by a later build choice, with the id). #### WP4-trio3 proposal for OQ-30 (for the GM; asserted in no file; merged with WP2-changeling's row above by WP6)

The package's recommendation, offered because the brief invites a proposal and forbids a decision: **there is no single maker.** Doppels are a *product category*, not one corporation's programme — each of the Big Three builds its own special units, the Almoners commission theirs, and there is a grey trade in bodies between them, which is why no two escapees on the Wall of Faces remember the same room and why none of them can name anyone. This has three advantages: it keeps the Bible's phrase "whoever built them" literal; it prevents a single corporate reveal from resolving the Cutloose's whole story; and it leaves the GM free to make any one maker matter later without contradicting a file. Everything this package wrote works unchanged if the GM instead names one maker — the Wall of Faces is written so that its fragments can be one room seen badly, or twenty rooms.
