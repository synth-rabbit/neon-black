# Deadband Kernel-Scanner Rig

**Catalog:** merc-gear · **Tags:** *Kernel-scanner rig*, *locate the master node*, *cross-references nanite density*, *slow readout* · **Flaws:** *requires setup* · **Requires setup:** yes

## Description

A handheld scanner from the same boutique anti-Bloodware line as [[em-pulse-cartridges|Deadband's EM rounds]], retuned to read nanite density gradients instead of implant serials. Correctly set up and swept slowly across a body, it can localize where a Bloodware subject's replication is densest — the master node, the thing that has to be destroyed. It takes a minute or more of careful sweeping to get a clean reading, and a subject who knows what the device is has every reason to keep moving.
