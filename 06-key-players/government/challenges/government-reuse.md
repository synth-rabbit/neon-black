# The Chancery — Challenge Reuse

Existing book Challenges [[government|the Chancery]] fields, per Brief §0.1. The custom profiles are [[chancery-process]] and [[envelope-detail]]. **[BUILD CHOICE]** (BC-119) `type: meta` — reuse index, not an entity.

**Standing rule for this Key Player.** Every police profile below is *exactly as legal* as a corporate security profile and no more (Bible §3). When both are in a scene, the difference between them is a page from [[halima-boyce]]'s office, not the law.
