# Meliora Bioworks — Challenge Reuse

Book Challenges [[corp-a|Meliora Bioworks]] fields, with pages and the re-flavor line. Custom content is **in addition to** book content, never instead of it (Brief §0.1); the three custom profiles are [[vice-president-marchetti]], [[sterile-field-unit]], and [[the-sterile-field]]. Generic needs shared with other Key Players belong to WP5's `08-challenges/generic-reuse-map.md`; this file lists only what Meliora itself puts in a scene.

## Characters

| Need | Challenge | Page | Re-flavor |
|---|---|---|---|
| A Meliora executive who is not Marchetti | **Corporate Executive** | Core p. 304 | Settling Sciences, Regulatory Affairs, or Terraces site management. Meliora execs avoid confrontation the way Epis execs do, but for a different reason: an incident is a report, and a report is an audit. |
| Terraces gate security, Spire lobby, clinic door | **Security Guard** | Core p. 305 | Meliora Security, warranty-card livery, non-lethal first because the building is full of glass and cultures. |
| Corporate investigator chasing a leak or a missing case | **Investigator** | Core p. 305 | Meliora Internal Assurance. Works paperwork, lift logs, and clinic records, not bodies. |
| Escort for an executive on the Crest or the Face | **Bodyguard** (Club VIP / Corporate Executive Specials) | Core p. 302, 304 | Sculpted, and the work is invisible because it is perfect. |
| A hired heavy element when Meliora does not want its own badge on it | **Mercenary Gunslinger** | Core p. 307 | Contracted through a broker so no Meliora requisition exists. |
| A Row surgeon or chop-shop cutter Meliora is quietly paying | **Shady Tech Merchant** | Core p. 303 | Re-flavored to flesh: a [[suture-row]] cutter with a Meliora aftercare account and a reason to keep it. |
| Corporate police response to an incident in a Meliora district | **Heavy Urban Response Tactics Officer** | Core p. 304 | Outsourced HURT services, per the entry's own note; on the Terraces they arrive after the [[sterile-field-unit]], not before. |
