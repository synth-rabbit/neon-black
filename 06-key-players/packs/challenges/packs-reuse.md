# The Run — Challenge Reuse

Book Challenges [[packs|the Run]] fields, with pages and the re-flavor line. Custom content is in addition to book content (Brief §0.1); the custom profiles are [[chimney]], [[pack-on-the-run]], [[uncle]], [[kiln-row]], and the [[running-shape]] overlay. Shared generics belong to WP5's `08-challenges/generic-reuse-map.md`.

**The rule that governs this whole file:** most of what a pack does, most of the time, is done by people who are not dosed. Howlers are rare (Bible §2) and a dose costs a week's price. Reach for a Gang Member first, and add [[running-shape]] only when the scene has earned it.

## Not used

- **Evolving Beast** (Core p. 316) — **[TAO-REINTERPRETED]** (CR-1) The book files it under *Source-Touched & Conjurations*. It is not the Run: a Howler is a person in a shape for a few hours, not an escalating monster, and using this profile for a pack would make the five read as beasts (Bible §2 rarity, no power asymmetry). It belongs to a failed settle that kept settling, which is [[corp-a-reuse]]'s entry, not this one.
- **Shapechanger** (Core p. 331) — a Mythos Power Set. Its shape is a legend's; [[running-shape]] is built from its skeleton with the Mythos removed, and the Mythos version is never applied to a Howler.
- **Oni Gangster, Ogre-King Hayao, Oni Rider, Oni Masked** (Tokyo p. 189–190) — the Tokyo gang profiles are the *format* model for this Key Player and the mask-and-legend content is unusable here. Nothing in the Run is Touched, masked, or mythic.
- **Corporate Sponsored, Connected & Protected** (Core p. 328) — the Run has no sponsor and no friends above the Foot. The joke is that both would be accurate if anyone in the Yards knew who makes the dose ([[corp-a]]).
