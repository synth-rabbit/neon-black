# Baselines — Existing Kits

Book kits recommended for a Baseline PC, from the Self and Noise themebooks (Brief §2.5). None needs mechanical re-flavor to work for a hunter — the fluff already fits a trained, geared, unmodified professional in a cyberpunk city. Setting-specific re-flavor notes are below each entry. See [[baselines|Baselines]] for the mapping these support (note: `overview` is a slug this file's own overview page shares with the megacity overview and, likely, its counterparts in the other `02-splats/` folders — see the WP6 note in `00-meta/additions/WP2-hunter.md`).

## Noise (optional secondary) — Augmentation: what's off-limits and what could be replacement-framed (Core p. 236–239)

**Every Augmentation kit printed in the Core Book is written to grant something *beyond* baseline function** — that is the themebook's stated purpose ("a person can gain superhuman strength, speed, skill, and senses," Core p. 236) — which means **none of the eight can be taken unmodified by a Baseline** without breaking the canon rule that hunter cybernetics only replace what was lost (Bible §2; BC-1). This package's own [[standard-issue-replacement]] is the only Augmentation kit built to pass that test from the ground up; the table below sorts the book's eight so a table knows why each one is off the list.

| Kit | Page | Status | Why |
|---|---|---|---|
| **Animalistic Modifications** | Core p. 238 | **Off-limits** | Explicit bio-engineering (*bioengineering, natural weapons, superior anatomy*) — the bio-manipulation line, not the cybernetics line. |
| **Impossibly Good Looks** | Core p. 239 | **Off-limits** | Explicit body sculpting (*alternate face, on-call plastic surgeon*) — the sculpting line by name. |
| **Armored Juggernaut** | Core p. 238 | **Off-limits** | Superhuman strength and armor plating (*brute force, mighty leap, pierce-proof plating*) — an enhancement, not a repair. |
| **Enhanced Senses** | Core p. 239 | **Off-limits** | Superhuman perception beyond any baseline eye or ear (*pierce through concealment, hear heartbeats*). |
| **Boosted Mental Capacity** | Core p. 238 | **Off-limits** | Superhuman cognition (*photographic memory, tactical assistant software*) beyond what any organic brain does. |
| **Reflex Booster Implants** | Core p. 239 | **Off-limits** | A chemical-dependency reflex boost (*adrenaline rush, burst of strength*) — closer to the werewolf trigger's shape than a hunter's; Brief §2.5 assigns it to werewolf trigger dependency, not hunter. |
| **Chipped Weapon Mastery** | Core p. 238 | **Off-limits** | Integrated targeting and telescopic eyes (*integrated targeting systems, telescopic eyes*) exceed baseline sight and aim; the Corpo-War Sniper trope (Core p. 178) pairs this kit with a hunter-adjacent concept, but a Baseline PC should swap it for [[surplus-combat-rig]] or [[standard-issue-replacement]] instead of taking it as printed. |
| **Hidden Gadgets** | Core p. 239 | **Borderline — usable only if heavily retagged** | Its content (*secret compartment, scanners and diagnostic tools, finger lockpick*) is the closest of the eight to gear-in-a-limb rather than a power boost. A table that wants this specific flavor should build it as a variant of [[standard-issue-replacement]] — every power tag rewritten to name a concealed utility a replacement limb carries, never a sense or a strength beyond what the original part had — rather than take the printed kit, whose Itch ("Surprise them with a new trick") and several tags still read as more than repair. |

## Canon and flags

- Bible §2 (cybernetics only as replacement; no sculpting or bio-manipulation) drives the Augmentation table above.
- **[BUILD CHOICE]** (BC-90) The Hidden Gadgets "borderline" ruling and the Corpo-War Sniper note are this package's judgment call, not a printed rule.
