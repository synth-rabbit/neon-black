# Existing Crew Kits

Three book crew kits worth offering this crew alongside the custom kits in `crew-kits/` — never instead of them (Plan A.1 rule 1). Tags are transcribed from Core p. 156–157; the printed page runs two kits side by side in parallel columns, and the text extraction used to build this vault merges those columns line by line. The counts below (ten power tags including the title, four weakness tags) are verified against the book's stated format (Core p. 75, 154); exact word order within a row is reconstructed by theme and should be checked against the printed card if a table needs it read aloud verbatim.

**Bible's caveat:** the crew is on [[palisade-player-primer#Amalgamated Prosthetic & Interface|AP&I]]'s escapee list, but "not important enough to warrant a bounty or targeted recapture" (Bible §6) — this crew is *not* Wanted in the book's hunted-hard sense. Offer this kit as the **"if the heat rises"** option: the shape to grow into if a job goes wrong and the escapee list stops being a formality, not the crew's starting condition. [[not-worth-the-bounty]] (a custom Crew Theme Special) is built on the opposite fact — that the heat has *not* risen yet — and stops applying the moment a table takes this kit.
